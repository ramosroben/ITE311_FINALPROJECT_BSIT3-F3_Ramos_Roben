# BentaHub: A Community Marketplace for Buying and Selling Pre-Loved Items

## Student Name
Roben V. Ramos

## Course and Section
Web System and Technologies 2 - BSIT 3-F3

## Project Description
BentaHub is a community marketplace that allows users to buy and sell pre-loved products such as clothes, gadgets, books, and accessories. The system provides product listings, online transactions, seller management, and transaction fee management to generate income for the platform.

## Technologies Used
PHP, Codeigniter 4, MySQL, Bootstrap, Git and GitHub
